NEON//WIRE DATA NODE
====================

This terminal provides access to archived corporate
infrastructure data.

Routine operational records are stored within the
standard archive.

SYSTEM NOTICE:

Emergency recovery records may be stored outside
the standard archive structure.

If a recovery operation is required, locate the
appropriate recovery record and provide its
authorization code to Network Operations.

SECURITY NOTICE:

Authentication events may be retained by the
security subsystem for operational diagnostics.

The archive node maintains its own internal clock.
When investigating authentication events, use the
NODE CLOCK reported by the terminal.
